dev-pocket 隐私政策

更新日期：2026 年 10 月 3 日

本政策说明 dev-pocket Chrome 扩展如何处理用户数据，适用于 1.2.0 版本。dev-pocket 提供 JSON 美化、信息编解码、时间戳转换、中英翻译、JSON 对比与标签管理功能。

本地数据处理

JSON 美化、信息编解码、时间戳转换和 JSON 对比在用户设备上执行。这些工具的输入与结果不会由扩展发送给开发者或其他服务器。扩展不设置开发者数据接收服务器，也不包含广告或行为统计功能。

标签管理

为了展示、分组、切换和整理标签，扩展会读取当前浏览器窗口中标签的标题、网址、标签标识以及浏览器缓存的网站图标。扩展不读取浏览器历史记录数据库。

用户主动保存到“稍后处理”及归档的记录，包括标题、网址、记录标识和相关时间，存储于本机的 chrome.storage.local，最多保存 500 条。记录不使用云端同步，也不上传到开发者服务器。用户可以在工具界面移除记录；卸载扩展会移除其本地存储。

点击标签或已保存记录时，浏览器将切换到或打开对应网站，该网站的数据处理受其自身政策约束。

翻译与发音

翻译需要连接第三方服务。用户在翻译工具中主动点击翻译、使用翻译快捷键、粘贴或拖入内容，或对已有内容切换翻译方向时，扩展会将待翻译文本及必要的语言、模型等请求参数发送给当前选择的服务商。

  • Google 翻译：文本发送到 translate-pa.googleapis.com，无需用户提供 API Key。
  • DeepSeek：文本发送到 api.deepseek.com。
  • 小米 MiMo：文本发送到 api.xiaomimimo.com。
  • 智谱 GLM：文本发送到 open.bigmodel.cn。

网页划词翻译仅在用户选中文字并主动点击扩展的翻译按钮时，向 Google 翻译发送所选文本。扩展不会为了翻译上传整页内容。用户点击发音按钮时，扩展会向 translate.google.com 发送需要朗读的文本和语言参数，获取语音音频。

第三方服务会接收为提供翻译或发音所需的数据，并可能收到网络连接的常规信息，例如 IP 地址。服务商对数据的保存、使用及计费受其各自政策和用户与其约定约束。用户应在发起翻译前确认相关文本适合发送给所选服务商。

API Key 和设置

用户提供的第三方 API Key、服务商选择、模型选择和翻译方向保存在本机扩展页面的 localStorage 中。API Key 以明文存储，不使用云端同步；发起请求时，仅作为身份验证凭证发送给该 Key 对应的服务商，不发送给开发者。

主题和标签关闭音效偏好也保存在本机。用户可以在界面修改设置，或通过卸载扩展清除扩展存储。用户可清空相应服务商的 Key 后保存设置，移除该服务商的已保存 Key。

数据使用与传输

dev-pocket 对用户数据的使用遵守 Chrome 应用商店用户数据政策，包括有限使用要求。通过 Google API 获取的信息也遵守上述政策和有限使用要求。

扩展仅为上述用户可见功能处理数据，不出售用户数据，不用于广告定向、信用评估、贷款或与工具功能无关的用途。第三方翻译与发音请求使用 HTTPS。所有可执行代码包含在扩展软件包中，服务商返回的译文作为数据展示，不作为远程代码执行。

扩展开发者不会通过本扩展接收用户的 JSON、编解码文本、时间戳、对比内容、标签列表、待办记录或第三方 API Key。

政策更新与联系

如扩展功能或数据处理方式发生变化，本政策将相应更新，并注明更新日期。有关功能和隐私问题，可通过 Chrome 应用商店中本扩展的商品支持入口联系开发者。
